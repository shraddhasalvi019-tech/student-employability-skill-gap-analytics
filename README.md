# Student Employability & Skill Gap Analytics

## Power BI CIAP Micro Project

### Project Overview

The **Student Employability & Skill Gap Analytics** project is an interactive Power BI dashboard developed to analyze the employability, academic performance, technical capabilities, professional exposure, and soft skills of undergraduate students.

The dashboard converts the given student dataset into meaningful visual insights and allows users to explore different aspects of student employability using interactive filters and page navigation.

---

## Objectives

- To analyze the overall employability of undergraduate students.
- To identify students across High, Medium, and Low employability levels.
- To analyze the relationship between academic performance and employability.
- To study students' technical and problem-solving capabilities.
- To analyze internship experience and professional exposure.
- To study soft skills and other career-related factors.
- To provide an interactive and easy-to-understand Power BI dashboard.

---

## Dataset

The project uses the **Undergraduate Employment Competitiveness Dataset**.

The dataset contains information related to:

- GPA and academic performance
- Academic consistency
- Programming skills
- Digital skills
- Communication skills
- Problem-solving skills
- Technical capabilities
- Internship experience
- Internship duration
- Online courses completed
- Project count
- Soft skills
- Leadership and teamwork
- Career clarity
- Career goal alignment
- Interview readiness
- Resume quality
- Target industry
- Employment competitiveness score
- Employment competitiveness level

The original dataset used for the dashboard is included in this repository.

# Dashboard Pages

## Page 1 — Executive Overview

The first page provides an overall summary of student employability.

### Key Information

- Total number of students
- Average employability score
- High employability students
- Medium employability students
- Low employability students
- Employability level distribution
- Average employability score by year of study
- Employability distribution by gender

Interactive filters and navigation buttons are provided to explore the dashboard.

---

## Page 2 — Academic & Technical Skills Analysis

The second page focuses on students' academic performance and technical capabilities.

### Key Analysis

- Average GPA
- Average programming/technical skill score
- GPA versus employability score
- Academic consistency
- Problem-solving performance
- Technical skill analysis
- Employability comparison across different levels

The page helps understand how academic and technical capabilities are associated with student employability.

---

## Page 3 — Professional & Soft Skills Analysis

The third page focuses on professional exposure, internships, online learning, target industries, and soft skills.

### Key Analysis

- Average internship count
- Average internship duration
- Average online courses completed
- Target industry distribution
- Internship experience versus employability
- Internship duration and employability by year
- Soft skill profile

The page provides insights into professional development and soft skills related to employability.
